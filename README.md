# Домашнее задание к работе 6

## Условие задачи

Дано четырехзначное число, выяснить является или оно
«перевертышем» (читается и с слева направо, и справа налево).

## 1. Алгоритм и блок-схема
### Алгоритм решения
1. **Начало**
2. Задать исходные данные: 
   - number(число)
3. Вычисления цифр:
    d1=number%1000
    d2=(number/100)%10
    d3=(number/10)%10
    d4=number%10
4. Вычисление:
    is_palindrome = (d1 == d4) and (d2 == d3)
5. Вывод результата:
is_palindrome ? "" : "НЕ "  
6. **Конец**
